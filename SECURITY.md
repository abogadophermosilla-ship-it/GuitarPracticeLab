# Seguridad

## Versiones soportadas

Mientras el proyecto esté en etapa temprana, las correcciones de seguridad se aplicarán únicamente a
la rama `main`.

## Reportar una vulnerabilidad

Usa **Security → Report a vulnerability** en GitHub si el repositorio tiene habilitados los reportes
privados. Si esa opción todavía no está disponible, abre un issue sin incluir el exploit, claves,
datos personales ni otros detalles sensibles y solicita un canal privado de contacto.

Incluye, de forma privada cuando corresponda:

- versión o commit afectado;
- pasos mínimos para reproducir el problema;
- impacto esperado;
- mitigación sugerida, si la conoces.

No publiques claves reales. Si una clave se expone, revócala primero en el proveedor correspondiente;
eliminarla de un commit posterior no la borra del historial de Git.
